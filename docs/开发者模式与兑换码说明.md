# 开发者模式与兑换码（作者专用说明）

> 网页版与 UrhoX 版使用**同一把私钥、同一套码**：同一个兑换码在两个版本里都有效；开发者码按设备码生成，网页版的设备码在浏览器本地存档里，UrhoX 的在设备存档里，各自单独生成。
> 改了私钥或作废编号后：`python3 tools/gen_codes.py syncjs`（只重写密钥文件）→ `python3 tools/build_preview.py`（网页版）→ `python3 tools/build_urhox_release.py`（UrhoX）。

## 它是怎么保证“只有作者能用”的
- 兑换码 / 开发者解锁码都是 **HMAC-SHA256 签名**：只有拿着私钥 `tools/author_secret.txt` 的人（你）才能生成有效的码，游戏里只做校验。
- **开发者码绑定设备码**：每台设备在存档里有一个随机 8 位设备码（设置 → 连点版本号 7 次，会显示设备码）。你用 `gen_codes.py dev 设备码` 生成的解锁码只对这台设备有效，别人拿到也没用。
- 解锁状态每次启动都会重新校验存档里的开发者码；直接改存档里的“已解锁”标记无效。
- 兑换码每个码每台设备只能兑换一次；连续输错 5 次锁定 60 秒；可以设有效期；可以作废某个编号。

## 重要限制（请知道）
离线游戏没有服务器，无法做到绝对安全：游戏脚本里存放的是**混淆后的校验密钥**，有人把发布包反编译出来就能取出密钥并自己造码。对付普通玩家足够；如果以后涉及真实收入或大规模发码，应改成服务器校验。
另外同一个兑换码可以被不同设备各用一次（没有服务器就没法全局去重），所以发码时请按“数额 / 人数 / 有效期”控制，必要时用“作废”。

## 日常使用（在源码包根目录执行）
```
python3 tools/gen_codes.py setkey                         # 第一次使用前先换成你自己的私钥（旧码全部失效）；然后重新生成发布包
python3 tools/gen_codes.py credits 5000                   # 1 个“信用点 +5000”兑换码
python3 tools/gen_codes.py src 100 --count 20 --note 测试群  # 20 个“星源 +100”兑换码
python3 tools/gen_codes.py src 300 --expire 2026-12-31    # 带有效期
python3 tools/gen_codes.py dev ABCD-1234                  # 为某台设备生成开发者解锁码
python3 tools/gen_codes.py list                           # 查看已发码（记录在 tools/code_ledger.json）
python3 tools/gen_codes.py revoke 17                      # 作废编号 17（需重新生成发布包才生效）
```
- 私钥文件 `tools/author_secret.txt` **不要发给任何人**，也不会进入 UrhoX 发布包；`setkey` / `revoke` 会重写 `scripts/cosmic/RedeemKey.lua`，之后要重新运行 `python3 tools/build_urhox_release.py`。

## 游戏里
- 玩家：设置 → “兑换码” → 用屏幕小键盘（电脑也可直接敲键盘）输入 24 位码 → 确认。
- 作者：设置 → 点“版本 vX”7 次 → 看到设备码 → 生成并输入解锁码 → 进入开发者面板。解锁后机库左上角有 DEV 标签，战斗里左侧有 DEV 按钮。
- 机库开发者面板：资源加减、解锁全部机甲 / 驾驶员、全章节通关、碎片、免费抽卡 / 芯片、重置每日、重播引导、保底清零、清空存档、调试信息、退出开发者模式。
- 战斗开发者面板：无敌、秒杀、满血、清场、升级 +1 / +5、加信用点 / 星源、下一星域 / 首领星域 / 星门前、调试信息（帧率、节点数、绘制数）、胜利 / 失败结算、战斗速度 x0.5 / x1 / x2 / x4。
