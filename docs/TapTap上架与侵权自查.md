# 宇宙银河机甲：侵权自查、风格与人群定位、TapTap 上架清单（v0.9.15）

> 说明：以下为开发者自查与建议，不是法律意见。正式上架前，涉及版权 / 商标 / 版号 / 软著的部分建议咨询律师或平台客服。

## 一、侵权自查

### 已检查并确认安全
- **关键词检索**：在全部源码、工具、文档里检索了常见机甲 / 动漫 / 游戏 IP 名称与机体编号（含高达、EVA、变形金刚、奥特曼、原神、明日方舟、机战等），没有命中。
- **模型**：全部由 `tools/*.py` 程序化生成的体素模型（机甲、角色、敌人、场景），没有导入第三方模型、贴图、`.vox` 素材。
- **音频**：音效与 3 首 BGM 均由 `tools/build_audio.py` 用代码合成，无采样、无引用现有旋律。
- **名称**：机甲 / 驾驶员 / 技能名（苍星、炎铠、月辉、琥珀工兵、霜鸣、天殒；星璃、赤焰、月汐、琥珀、霜铃、夜鸢）均为通用中文词汇组合，未发现与知名作品的专有名词重合；建议上架前在应用商店、国家商标局网站各搜一次，确认游戏名“宇宙银河机甲”和机甲名没有被他人在游戏类别注册。
- **字体**：Noto Sans SC、站酷庆科黄油体均为 SIL OFL 开源字体，可商用；已在游戏内“关于与合规”页声明。

### 已处理的风险点
- **苍星（原：白蓝配色 + 头顶后掠 V 形天线 + 光束步枪 + 盾牌）** 与经典量产型主角机的“白蓝 + V 字天线”轮廓过于接近。已修改：配色改为白 + 深青；去掉 V 形天线，改为中央刃冠 + 两侧圆形传感舱。
- 其余机甲：炎铠（红色重装 + 斧）、月辉（光环 + 法杖）、琥珀工兵（黄黑 + 吊臂）、霜鸣（蓝白 + 肩部导弹舱）、天殒（黑金 + 长枪与翼）的轮廓均为通用元素组合，没有发现明确对应某部作品的特征。

### 仍建议你自己做的事
1. 上架前把 6 台机甲和 6 位驾驶员的正面图，用图片反向搜索（Google 图片 / 百度识图）各查一次。
2. 游戏名、图标、截图中不要出现任何第三方 IP 的元素。
3. 驾驶员头像（像素风）若使用 AI 生成，需确认所用工具的商用条款。
4. 申请软件著作权（软著），保留开发记录（本工程的源码与 README 更新日志可作为证据）。

## 二、风格：体素 Q 版 vs 帅气

**结论：保持“体素 + 偏 Q 版的比例”，但把机甲的“帅气感”放在细节与动作上，而不是改成写实。**

理由：
1. 体素风本身有辨识度，TapTap 上同类产品（割草 / 生存 + 体素）用户接受度高，小体积、低配机型也跑得动。
2. 写实帅气需要高精度模型与动画，体素分辨率撑不起来，反而显得粗糙。
3. “Q 版比例”（大头 / 粗腿）更适合手机小屏：角色在屏幕上只有 150~250 像素高，轮廓必须一眼读得出。

怎么在 Q 版里做出帅气：
- 动作与特效：这一轮已经做了尾喷、氮气、肘关节、技能光束，继续强化。
- 剪影：每台机甲的头冠 / 肩甲 / 武器要在剪影上就能区分（目前已基本做到）。
- 配色克制：深色底 + 一个强调色 + 发光色，不要多色堆砌。
- 觉醒 / 星级外观：高星级加发光纹路、翼 / 披风等外观升级，满足“变帅”的追求。
- 加一个“帅气展示”机库：长按旋转、拍照模式、技能展示。

## 三、人群定位

| 维度 | 建议 |
|---|---|
| 核心人群 | 16~35 岁、喜欢科幻 / 机甲 / 收集养成的手游玩家；碎片时间玩 5~10 分钟一局 |
| 次级人群 | 喜欢割草 / 幸存者类、爽快清屏的轻度玩家 |
| 卖点 | 一局 6 分钟；每台机甲手感和打法不同；技能卡牌组合（1080 张）；体素风小体积 |
| 不适合 | 重度剧情党、要求写实画质的玩家 |
| 适龄 | 12+（卡通科幻战斗，无血腥） |

## 四、整体还能调整什么

### 玩法与留存
1. **新手前 3 局要“爽”**：开局送一张金卡体验券；第一局 2 分钟内让玩家升到 5 级。
2. **每日目标 + 登录奖励 7 天**：现在每日只有补给与任务，缺“连续登录”的钩子。
3. **成就 / 图鉴**：卡牌图鉴已有，再加“击败全部首领”“收集 100 张卡牌”等成就与奖励。
4. **局内变化**：词缀与新事件已有，还可以加“每 3 局一个周限时挑战（限定机甲 / 限定词缀）”。
5. **难度曲线**：第 2、3 章已下调倍率，并提供推荐战力；上线后看真实通关率，再调。
6. **结算页**：显示“本局成长”（等级、拿到的卡牌、伤害来源占比），促进再来一局。

### 商业化（符合 TapTap 与国内规范）
1. 看广告：把激励视频接到真实广告 SDK（TapTap 广告联盟 / 穿山甲 / 优量汇）；现在是模拟逻辑（`C.showAd`）。
2. 内购：先只做“去广告 / 月卡 / 新手礼包”，不做强付费数值；抽取要继续公示概率（已加入“关于与合规”页）。
3. 国内上线需要：**版号**（含内购必须；纯单机免费无内购情况以平台最新规定为准，请向 TapTap 客服确认）、**实名认证与防沉迷**（接入 TapTap 实名 / 防沉迷 SDK）、**隐私政策与用户协议**、**未成年人充值与时长限制**。

### 技术与性能
1. 现为单文件 HTML：体积约 2.1 MB，首次加载包含全部音频，建议后续拆成分包并开启 gzip。
2. 字体：当前用 Google Fonts 在线加载，国内部分网络加载慢甚至失败，会回退系统字体。建议把两款字体做字体子集（只含用到的汉字）并随包内置。
3. 手机适配：触控摇杆 / 氮气 / 技能键布局建议在 5~7 寸真机上调；平板与折叠屏再单独测。
4. 横竖屏：目前按横屏设计；若想做竖屏需要重新排版 HUD。
5. 存档：目前只存本机，建议接入账号云存档（TapTap 账号）防止清缓存丢失。
6. 崩溃监控与埋点：接入基础统计（启动、第一局完成率、第 3 局留存、卡点关卡）。

### 上 TapTap 的材料清单
- 图标（512x512）、横版封面图、5 张以上截图（含战斗、机库、技能卡牌、首领战）、10~30 秒玩法视频。
- 简介（一句话卖点 + 玩法 + 特色）、标签（机甲 / 体素 / 割草 / 肉鸽 / 单机）。
- 隐私政策链接、用户协议链接、适龄提示、版权声明、联系方式。
- 先走“测试 / 预约”渠道收集反馈，再正式发布。

## 六、v0.9.19 造型与风险补充

- 现在六台机甲统一为“体素 + Q 版比例”（大头、短腿、粗躯干），与写实比例的经典机甲区别更大，轮廓风险进一步降低。
- 剪影差异：苍星（圆头 + 脑后雷达环 + 脉冲护臂，无盾）、炎铠（红色重装 + 金色角冠 + 热能斧）、月辉（半圆光环 + 新月法杖）、琥珀工兵（黄黑工程配色 + 双天线 + 双机炮）、霜鸣（长兔耳传感器 + 肩部导弹舱 + 背负轨道炮）、天殒（黑金骑士盔 + 晶翼 + 星核长枪）。
- 仍需注意：炎铠“红色 + 金色头角”与部分经典红色指挥官机的配色联想较近，上架前可考虑把角冠改成非对称或改配色（例如暗红 + 青）；这属于风格联想，不一定构成侵权，但建议你用图片反搜确认。
- “体素 + Q 版”可行性：可行，且适合手机——一个体素机甲在屏幕上约 200 像素高，Q 版大头让表情 / 头冠 / 护目镜更清晰；缺点是体素分辨率低，头部细节（表情、徽章）有限，所以要靠剪影、配色和发光点来区分。


## 七、TapTap 首页推荐宣传片规范与本工程的宣传片

**平台要求（首页推荐视频）**：仅支持横屏；长度不少于 15 秒；格式 .mp4 或 .mov；编码 H.264 / HEVC(H.265)；文件不超过 5GB；比例 16:9，分辨率不低于 1280x720；宣传片内容不得与实机视频高度雷同。

**本工程提供的宣传片（动态版）**：`marketing/宇宙银河机甲_宣传片.mp4`
- 参数：1920x1080 / 30fps / H.264 High + AAC 立体声（44.1kHz）/ 约 30 秒 / 约 33MB（已用 ffprobe 核对），横屏 16:9，满足上述全部要求（已用 ffprobe 核对）。
- 内容：片头标题 -> 六台机甲逐一展示（含等级）-> 战斗高光（射线、炮台、导弹雨、陨星、首领激光、混战）-> 玩法特色（1080 张卡牌、危险等级与无尽模式、SSSR 召唤、每日挑战 / 7 日登录）-> 片尾。画面为游戏内逐帧录制的动态镜头（含飞行、开火、技能、首领激光、元素反应）配动态字幕与转场，音乐为游戏自带 BGM，原创无版权风险。
- 与实机视频的区分：宣传片以展示 / 字幕 / 节奏剪辑为主，实机视频请另行录制真实操作画面，避免内容高度雷同。
- 重新生成：先用 `tools/trailer_record/vscenes.py` 录制镜头帧，再运行 `tools/make_trailer2.py`（需要 ffmpeg 与 Noto Sans CJK 字体；玩法卡片使用 `marketing/trailer_stills/ui_*.jpg`）。
- 建议升级：真机录制更动态的镜头、加入配音 / 解说、片头加品牌 Logo；片中“TapTap 测试招募中”字样请按实际上线状态修改。
