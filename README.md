# 宇宙银河机甲

体素风机甲动作手游原型。星魂少女驾驶原创体素机甲，以太空第三人称视角闯过 6 个星域击败首领；
局外分别召唤机甲与驾驶员（S / SS / SSR），在工坊研发随机技能模块与天赋芯片。
玩法设计见 `docs/宇宙银河机甲_玩法设计.md`，世界观见 `docs/陨星银河_设定集.md`。

## 操作

手机：左下拖动转向，左侧滑条调油门，右下按住开火 / 加速，点导弹、目标、导航；靠近星港或星门时中间出现停靠 / 跃迁按钮。

电脑：WASD 或方向键转向，R/F 油门，空格开火，Q 导弹，Shift 加速，T 切换目标，G 自动导航，E 停靠或跃迁，M 星图，Esc 暂停。

## 分辨率适配

横屏 1920 x 1080 设计，UI 缩放 = min(屏幕宽 / 1920, 屏幕高 / 1080)，UI 用设计像素书写并贴边布局。
19.5:9 / 20:9 手机左右多出的空间留给画面，UI 避开刘海与手势条；4:3 平板自动放大相机竖直视角，保证水平视野不变。
